Soalan lazim

Maklumat ringkas tentang laman ini.

Adakah muat turun sudah berfungsi?

Enjin backend kini tersedia dalam folder backend. Selepas servis backend dihoskan dan URL API dimasukkan ke dalam API_BASE di index.html, butang muat turun akan memproses video. Hosting GitHub Pages sahaja tidak menjalankan backend.

Kenapa perlu backend?

Pemprosesan video berjalan pada servis backend berasingan. Jangan letakkan kunci rahsia di dalam kod browser.

Bolehkah saya guna pada telefon?

Ya, antaramuka ini direka responsif untuk telefon dan komputer. Sambungan internet diperlukan untuk menggunakan servis luar apabila enjin muat turun disediakan.

Adakah saya boleh menyimpan semua video?

Simpan hanya kandungan yang anda miliki atau mempunyai kebenaran untuk memuat turun. Hormati privasi pencipta dan syarat platform.
